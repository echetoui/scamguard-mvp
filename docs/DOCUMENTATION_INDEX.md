## 📝 Guide de Maintenance de la Documentation

### Ajouter une Nouvelle Doc
1. Créer le fichier avec le pattern: `FEATURE_DESCRIPTION.md`
2. Ajouter une entrée dans l'index approprié ci-dessus
3. Inclure une date de dernière mise à jour
4. Mettre à jour ce fichier

### Archiver une Doc Obsolète
1. Déplacer le fichier vers `docs/archive/`
2. Mettre à jour ce fichier
3. Mettre à jour le README.md si nécessaire

### Mettre à Jour une Doc Existante
1. Modifier le fichier
2. Ajouter/mettre à jour la date de dernière mise à jour
3. Si le contenu change significativement, notifier dans `ACTION_PLAN_2026_02_22.md`
