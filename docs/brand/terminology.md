## Grammar Rules (Quebec French)

### Articles
- **Use "un" / "une" / "des"** not "le" / "la" for approachable tone
- ✅ "Reçu un courriel suspect" (friendly)
- ❌ "Le courriel suspect" (formal)

### Pronouns
- **Always "vous" (formal singular)**, never "tu" (too familiar)
- **Avoid "on" as substitute for "nous"** in formal UI ("Nous avons repéré" not "On a repéré")
- **First-person plural for protection**: "Nous allons vous aider"

### Capitalization
- **Proper nouns only**: "ScamGuard", "Desjardins", "GRC"
- **Not all caps for emphasis**: Use emoji instead (✅ not 🚨 URGENT!)
- **Buttons title case**: "Signaler à la Police", not "signaler à la police"

### Verb Tense
- **Present tense for actions**: "Cliquez" (click), not "Cliquer" (infinitive alone)
- **Simple present for explanations**: "C'est une arnaque" (it is), not "Ceci pourrait être" (could be)
- **Conditional for suggestions**: "Vous pourriez", "Vous devriez"

### Contractions
- **Use natural contractions**: "c'est", "qu'est", "l'", "d'"
- **Makes text friendlier**, not formal

### Punctuation
- **No excessive punctuation**: "Arnaque détectée." not "Arnaque détectée!!!"
- **Use periods properly**: Each sentence ends with period in lists

## Messages by Type

### Success Messages
```
✅ [Action completed]
[Brief positive reinforcement]
[Optional: Next step]
```

**Examples:**
- "✅ Code envoyé. Vérifiez votre cellulaire."
- "✅ Message signalé. Merci de protéger la communauté!"

### Error Messages
```
❌ [What went wrong]
[Why it happened — sentence max]
[How to fix]
[Optional: More help link]
```

**Examples:**
- "❌ Code incorrect. Vous avez 2 essais restants. Vérifiez votre SMS."
- "❌ Courriel non trouvé. Assurez-vous d'avoir entré le bon courriel."

### Warning Messages
```
⚠️ [Heads up]
[Context]
[What happens if you continue]
[Options: Accept / Cancel]
```

**Examples:**
- "⚠️ Cet SMS ressemble à une arnaque. Voulez-vous vraiment répondre? [Oui / Non]"

### Informational Messages
```
ℹ️ [FYI]
[Explanation]
[Optional: Learn more link]
```

**Examples:**
- "ℹ️ Les banques ne demandent jamais votre mot de passe par SMS. En savoir plus >"
