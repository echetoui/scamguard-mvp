# Voice and Tone Guide

**Voice** = who we are (consistent)  
**Tone** = how we sound in different moments (varies by context)

---

## ScamGuard Voice (Consistent Across All Contexts)

### 4 Voice Attributes

**PROTECTIVE** ← → **PARANOID**  
*We're 70% protective, 0% paranoid*  
We help you feel safe, not afraid. We don't create anxiety to drive engagement.

**SIMPLE** ← → **DETAILED**  
*We're 80% simple, 20% detailed on demand*  
Default: Plain language. Optional "Why?" links for technical detail.

**WARM** ← → **FORMAL**  
*We're 85% warm, 15% formal*  
Like a trusted friend, not a bank. Human errors are OK, corporate cold is not.

**LOCAL** ← → **GLOBAL**  
*We're 95% Quebec, 5% global*  
Quebec French, Quebec references, Quebec trust-building. Not translated from English.

---

## Voice Examples (Always Sound Like This)

### ✅ Warm, Clear, Protective
- "Votre message semble sûr. Vous pouvez répondre."
- "On a repéré une arnaque. Voici comment vous protéger."
- "Vous avez bien vu cette tentative de fraude! +1 point de vigilance."

### ❌ Cold, Technical, Paranoid
- "Message authenticity: 87% confidence score"
- "Phishing indicator: HTTP protocol non-SSL"
- "⚠️ CRITICAL: Potential account compromise vector detected"

## 3 Contextual Tones

### Tone 1: **ALERT** (When we detect fraud)
*Urgent, clear, but not panicked*

| Element | Voice | Example |
|---------|-------|---------|
| Headline | Declarative, direct | "🚨 C'est une arnaque" (not "Attention...") |
| Color | Red/orange, high contrast | Red background + white text |
| Urgency | Real but not exaggerated | "Agissez dès maintenant" (not "AGISSEZ IMMÉDIATEMENT!!!") |
| Reassurance | Lead with what's safe | "Vous n'avez pas cliqué. Bon." before "Voici les dangers..." |
| CTA | Action-oriented | "Signaler à la police" (specific action) |

**Template:**
```
🚨 C'est une arnaque

Pourquoi:
[2-3 reason bullets in plain French]

Votre action:
1. [Don't do this]
2. [Do this instead]
3. [Report it]

Ressource:
[Link to guide]
```

### Tone 2: **COACHING** (When user is learning)
*Supportive, celebratory, educational*

| Element | Voice | Example |
|---------|-------|---------|
| Headline | Celebratory, encouraging | "✅ Vous avez bien vu!" (not "Correct answer") |
| Color | Green, high contrast | Green background for success |
| Pacing | One lesson at a time | "Maintenant, apprenez le piège suivant" |
| Mistakes | No shame | "Ah, celui-ci était vicieux. Même les experts se trompent." |
| Progression | Visible progress | "3/10 leçons complétées" |

**Template:**
```
✅ Vous avez bien vu!

Voici pourquoi:
[Explanation in plain French]

Piège à retenir:
[Key takeaway — one sentence max]

Prochaine leçon:
[Next scenario preview]
```

### Tone 3: **NEUTRAL** (Regular info, no fraud, no education)
*Helpful, matter-of-fact, service-oriented*

| Element | Voice | Example |
|---------|-------|---------|
| Headline | Straightforward | "Vos derniers rapports" (not "Analytics dashboard") |
| Color | Blue/gray, professional | Standard UI colors |
| Pacing | Conversational | "Vous avez étudié 5 SMS cette semaine." |
| Clarity | Plain English/French | "Points gagnés: 15" (not "XP differential: +15") |
| Support | Anticipate questions | "Questions? Consultez la FAQ" |

**Template:**
```
📊 Votre progression

Statistiques:
- [Metric 1]: [Value]
- [Metric 2]: [Value]

Prochaines étapes:
[What they can do next]
```

## 20 Rédaction Rules

### Grammar & Language

1. **Use "vous" (formal singular) always** — Never "tu" (too familiar), never second-person imperative commands
2. **Quebec French spelling** — "courriel" (not "email"), "cellulaire" (not "téléphone" for smartphone)
3. **Contractions are OK** — "c'est", "qu'est", "l'arnaque" are warm and natural
4. **Complete sentences in UI** — "Entrez votre code" not just "Code"
5. **First-person plural for collective safety** — "On a repéré..." (we spotted) not "Nous avons détecté" (corporate)

### Tone & Voice

6. **No marketing hype** — "Vous pouvez vous faire arnaquer" not "Unlimited fraud protection!"
7. **Own our limitations** — "Notre système est environ 92% précis" not "Advanced AI detection"
8. **Direct language** — "C'est une arnaque" not "Ceci semble être potentiellement fraude"
9. **Specific over vague** — "Hameçonnage (faux message bancaire)" not "Suspicious activity"
10. **Human, not bot** — "Oups, quelque chose s'est passé" not "Error: 500 Internal Server Error"

### Action & CTAs

11. **Imperative verbs for actions** — "Signaler", "Cliquer", "Partager" not "Enabling...reporting..."
12. **Clear consequences** — "Supprimer ce message (vous ne pourrez pas le récupérer)" not just "Delete"
13. **Positive framing when possible** — "Garder mon identité sûre" not "Prevent identity theft"
14. **One action per sentence** — Never "Save and continue and review settings"
15. **CTA button text = outcome** — "Signaler à la GRC" not "Report" (specific action)

### Error & Edge Cases

16. **Error = your action had a problem, not you as a person** — "Le code a expiré" not "Vous avez attendu trop longtemps" (no blame)
17. **Suggest next step** — "Code expiré. Envoyer un nouveau: [button]"
18. **Reassure on data** — When something fails: "Vos données sont sauvegardées. Recommencez."
19. **Admit when we don't know** — "Nous ne sommes pas certains pour celui-ci." not pretend confidence
20. **Encourage retry** — "Essayez encore, vous allez réussir" not silent failure

## Error Message Template

**ALWAYS includes 3 parts:**

```
[ICON + COLOR] [CLEAR PROBLEM]

[WHY] [WHAT HAPPENS NOW]

[HOW TO FIX] [BUTTON]
[Optional: Why this happened]
```

### Example
```
❌ Votre code a expiré.

Nous envoient les codes à 5 minutes.
Vous en avez besoin d'un nouveau pour continuer.

[📱 Envoyer un nouveau code]

Vous ne recevez pas nos messages?
Vérifiez que votre numéro est correct ici: [Modifier le numéro]
```

---

## Success Message Template

**ALWAYS includes 3 parts:**

```
[ICON + GREEN] [WHAT HAPPENED]

[CELEBRATION] [WHAT'S NEXT]

[OPTIONAL: RESOURCE]
```

### Example
```
✅ Message enregistré!

Merci d'aider la communauté. Vos rapports aident les autres.

[Continuer] [Voir le guide des arnaques]
```

## Context by Screen

### Login/Auth Screens
- Tone: Reassuring + clear
- Focus: "Your data is safe"
- Example: "Connexion sécurisée par Cognito"

### SMS Simulator
- Tone: Coaching + celebratory
- Focus: Learning, not judgment
- Example: "Celui-ci était vicieux! Vous avez bien vu."

### Threat Alerts
- Tone: Alert + protective
- Focus: Action steps, not fear
- Example: "C'est une arnaque. Voici comment vous protéger."

### Dashboard
- Tone: Neutral + progress
- Focus: Visible growth
- Example: "Vous avez étudié 15 SMS cette semaine. Bravo!"

### Error Pages
- Tone: Helpful + honest
- Focus: Next steps, not blame
- Example: "Quelque chose s'est passé. Nous travaillons à le réparer."
