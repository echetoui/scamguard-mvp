# 🛡️ ScamGuard AI - MVP Semaine 0

Protection des seniors contre les arnaques par IA.

## Architecture

- **Frontend:** React PWA
- **Backend:** AWS Lambda + Python
- **LLMs:** Gemini 1.5 Flash + GPT-4o-mini
- **Infrastructure:** AWS CDK
- **Database:** DynamoDB

## Coût

~$3-5/mois pour 10 utilisateurs
