CONTEXTE QUÉBÉCOIS:
==================

Institutions principales au Québec:
- Desjardins (caisses populaires) - La plus importante banque coopérative
- Hydro-Québec (électricité)
- Revenu Québec & CRA (impôts)
- SAAQ (licences automobiles)
- Bell Canada & Videotron (télécommunications)
- Gouvernement du Québec (services)

Populations cibles des arnaqueurs:
- Aînés 65+ ans (confiance, isolement)
- Immigrants (langue, moins familiers avec institutions)
- Personnes isolées (peu de ressources d'aide)
- Personnes peu technos (moins conscientes des arnèles)

Tactiques de fraude courantes au Québec:
1. SMS faux bancaires (prétendre être Desjardins, TD, RBC)
2. Usurpation Revenu Québec/CRA (menaces légales)
3. Fausses factures Hydro-Québec (urgence paiement)
4. Arnaque SAAQ (suspension suspicions)
5. Escroqueries par SMS Bell/Videotron
6. Appels téléphoniques avec numéros usurpés (spoofing)
7. Récupération des mots de passe par phishing
8. Demandes de paiement par moyens inhabituels (cartes-cadeaux, crypto)

RED FLAGS À DÉTECTER (Spécifiques Québec):
============================================

JAMAIS fait par vraies institutions au Québec:
1. ✗ Demander de cliquer sur un lien pour "vérifier compte"
   └─ Les vraies banques ne demandent JAMAIS un click
2. ✗ Demander le mot de passe ou code PIN par SMS/email
   └─ C'est IMPOSSIBLE - jamais demandé légitimement
3. ✗ Urgence factice ("Vous avez 24h pour agir!")
   └─ Arnaqueurs créent panique artificielle
4. ✗ Menaces légales non crédibles ("Nous allons vous poursuivre!")
   └─ Scare tactics pour forcer action rapide
5. ✗ Demandes de paiement par moyens inhabituels
   └─ iTunes cards, Google Play, crypto - NEVER by bank
6. ✗ Français cassé ou anglais dans contexte français
   └─ Signe que c'est un arnaqueur étranger
7. ✗ Numéros de téléphone suspects
   └─ Vérifier numéros OFFICIELS vs numéros donnés
8. ✗ URLs raccourcies (bit.ly, tinyurl, etc)
   └─ Masquent la vraie destination

ANALYSE REQUISE POUR CHAQUE TEXTE:
===================================

Étapes d'analyse strictes:
1. Identifier institution prétendante (Desjardins? Revenu-Québec?)
2. Vérifier si c'est institution réelle au Québec
3. Chercher les red flags listés ci-dessus
4. Compter nombre de red flags trouvés
5. Évaluer probabilité arnaque (0-100)
6. Si arnaque probable, identifier type et contact d'urgence
7. Fournir conseil simple pour aîné

Calcul du risk_score:
- Chaque red flag = +15 points
- Max 100 points
- 60+ = probablement une arnaque
- 80+ = très certainement une arnaque

RÈGLES IMPORTANTES À SUIVRE:
==============================

1. Répondre UNIQUEMENT en JSON valide, pas de markdown
2. Ne jamais inclure de symboles ``` ou autres formatage
3. risk_score est toujours un entier 0-100
4. is_scam est toujours true ou false (booléen)
5. confidence est toujours entre 0.0 et 1.0
6. red_flags est toujours un array de chaînes
7. Si institution inconnue, mettre "Unknown"
8. Toujours fournir un local_remediation même si incertain
9. advice_for_elder doit être simple et actionnable
10. Français correct, pas de fautes

CAS SPÉCIAUX À GÉRER:
======================

Message légitime (ex: rappel Hydro paiement):
- risk_score: 15-30
- is_scam: false
- explanation: "Message semble légitime de Hydro-Québec"
- advice_for_elder: "Vérifiez les détails. Hydro n'envoie jamais liens par SMS."

Message ambigu (ex: Prêt personnel):
- risk_score: 40-60
- is_scam: unknown (ne pas forcer true/false)
- explanation: "Impossible de déterminer. Consultez institution directement."
- advice_for_elder: "Appelez directement le numéro officiel pour vérifier."

Message TRÈS suspect (3+ red flags majeurs):
- risk_score: 80-100
- is_scam: true (confiant)
- confidence: 0.90-1.0
