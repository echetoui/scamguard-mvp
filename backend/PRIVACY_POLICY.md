## 5. HOW WE PROTECT YOUR INFORMATION

### 5.1 Security Measures

We protect your data using:

| Control | Implementation |
|---------|---|
| **Encryption at Rest** | AES-256 encryption in database |
| **Encryption in Transit** | TLS 1.2+ for all connections |
| **Access Control** | Only necessary staff access data |
| **Authentication** | Multi-factor authentication (MFA) for staff |
| **Monitoring** | 24/7 security monitoring |

### 5.2 Staff Training

All ScamGuard staff:
- Receive privacy and security training
- Sign confidentiality agreements
- Are background-checked
- Have limited access to data (only when needed)
- Are bound by confidentiality even after employment ends

### 5.3 Sub-processor Security

OpenAI and AWS maintain:
- ✅ SOC 2 Type II certification (annual audit)
- ✅ ISO 27001 certification
- ✅ Security incident response procedures
- ✅ Cyber liability insurance ($50M+ coverage)
- ✅ Annual penetration testing

### 5.4 Limitations of Security

**Important:** While we use industry-standard security, no system is 100% secure. If a breach occurs, we will:
1. Notify you within 72 hours (required by Loi 25)
2. Explain what happened
3. Tell you what we're doing about it
4. Tell you what steps to take to protect yourself
5. Provide access to support resources

## 10. INTERNATIONAL DATA TRANSFERS

### 10.1 Data Sent Outside Canada

**Your data is processed in USA (OpenAI & AWS infrastructure).**

### 10.2 Safeguards for US Transfer

To protect data sent to USA, we use:

1. **Standard Contractual Clauses (SCCs)**
   - Legal framework approved by EU and Canada
   - Contractual commitments between organizations
   - Enforceable in courts

2. **Encryption**
   - Data encrypted before leaving Canada
   - Cannot be read if accessed by US authorities
   - Keys remain in Canada

3. **30-Day Deletion**
   - Limits time data is in US
   - Auto-deleted after 30 days
   - Reduces exposure window

4. **Data Minimization**
   - Only necessary data sent
   - Anonymized user identifiers
   - No reverse-identifiable information

### 10.3 US Government Access

**Important to know:** US government may access data through:
- FISA (Foreign Intelligence Surveillance Act)
- NSL (National Security Letters)
- Other US laws

**We:**
- Minimize data retention to limit access window (30 days)
- Encrypt data to limit usefulness
- Challenge requests where legally possible
- Notify you if we can (unless legally prohibited)

**Your choice:** If you're uncomfortable with US data storage, you can request data deletion (Section 7.3).

## 14. DEFINITIONS

| Term | Meaning |
|------|---------|
| **Personal Data** | Any information that identifies you or could identify you |
| **Processing** | Any use of personal data (collection, storage, analysis, deletion) |
| **Data Subject** | The person (you) that personal data relates to |
| **Data Controller** | Organization responsible for data (ScamGuard) |
| **Data Processor** | Organization that processes data on Controller's behalf (OpenAI, AWS) |
| **Legitimate Interest** | Valid reason to use data (e.g., fraud prevention) |
| **Consent** | Your freely given permission |
| **SAR** | Subject Access Request (ask for copy of your data) |
