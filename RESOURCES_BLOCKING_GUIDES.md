## 📖 GUIDE 1: BLOCAGE SUR ANDROID

### A. Bloquer un Appel Téléphonique

**MÉTHODE 1: Directement depuis l'appel**

```
1. Ouvrir l'app Téléphone
2. Appuyer sur l'onglet "Historique" (Récents)
3. Trouver le numéro à bloquer
4. Appuyer longtemps dessus
5. Sélectionner "Bloquer le numéro"
6. Confirmer "Bloquer"

✅ C'est fait! Les futurs appels seront bloqués.
```

**MÉTHODE 2: Via les Paramètres**

```
1. Ouvrir l'app Téléphone
2. Appuyer sur ⋮ (3 points) > Paramètres
3. Appuyer sur "Numéros bloqués"
4. Appuyer sur (+) Ajouter
5. Entrer le numéro ou sélectionner un contact
6. Appuyer sur "Bloquer"

✅ Complété!
```

**MÉTHODE 3: Depuis un Contact**

```
1. Ouvrir Contacts
2. Sélectionner le contact suspect
3. Appuyer sur ⋮ (3 points)
4. Sélectionner "Bloquer le numéro"
5. Confirmer

✅ Contact bloqué!
```

### B. Bloquer un SMS

**MÉTHODE 1: Depuis l'app Messages**

```
1. Ouvrir l'app Messages (SMS)
2. Ouvrir la conversation à bloquer
3. Appuyer longtemps sur le message
4. Appuyer sur "Bloquer" ou "Ajouter à la liste noire"
5. Confirmer

✅ SMS futurs de ce numéro seront bloqués.
```

**MÉTHODE 2: Bloquer + Signaler**

```
1. Ouvrir le message suspect
2. Appuyer sur ⋮ (3 points)
3. Sélectionner "Bloquer et signaler comme spam"
4. Appuyer sur "Bloquer"

ℹ️ Cela aide Google à identifier les spammeurs.
```

### C. Whitelist: Contacts de Confiance

**Mettre en Favori les Contacts Importants**

```
1. Ouvrir Contacts
2. Sélectionner le contact (famille, amis, travail)
3. Appuyer sur l'étoile (⭐) pour ajouter aux favoris
4. Vous pouvez aussi les appeler directement

✅ Ils apparaîtront en premier dans vos appels.
```

### D. Consulter et Débloquer

**Voir vos Numéros Bloqués**

```
1. Ouvrir Téléphone > Paramètres
2. Appuyer sur "Numéros bloqués"
3. Voir la liste complète des numéros bloqués

Pour débloquer:
1. Appuyer longtemps sur le numéro
2. Sélectionner "Débloquer"

ℹ️ Les appels/SMS bloqués vont directement aux spam.
```

## 📖 GUIDE 2: BLOCAGE SUR IPHONE

### A. Bloquer un Appel Téléphonique

**MÉTHODE 1: Depuis les Appels Récents**

```
1. Ouvrir l'app Téléphone
2. Aller dans "Récents"
3. Trouver le numéro suspect
4. Appuyer sur l'icône ⓘ (info) à côté
5. Scroller vers le bas
6. Appuyer sur "Bloquer ce contact"
7. Confirmer "Bloquer le contact"

✅ Bloqué! Les futurs appels seront silencieux.
```

**MÉTHODE 2: Depuis Contacts**

```
1. Ouvrir Contacts
2. Trouver le contact suspect
3. Appuyer sur "Modifier"
4. Scroller vers le bas
5. Appuyer sur "Bloquer ce contact"
6. Appuyer sur "Bloquer le contact" pour confirmer

✅ Contact bloqué!
```

### B. Bloquer un SMS

**Bloquer depuis Messages**

```
1. Ouvrir Messages
2. Ouvrir la conversation à bloquer
3. Appuyer sur le numéro en haut
4. Appuyer sur "ⓘ" (Info)
5. Appuyer sur "Bloquer ce contact"
6. Confirmer "Bloquer le contact"

✅ SMS futurs seront filtrés.
```

### C. Filtrer les SMS Suspects

**Activer le Filtrage des SMS**

```
1. Ouvrir Messages
2. Appuyer sur "Éditer" (en haut)
3. Sélectionner "SMS indésirables" ou "Spam"
4. Appuyer sur "Modifier" > "Masquer les alertes"

✅ Les SMS spam sont automatiquement triés.
```

### D. Consulter vos Blocs

**Voir et Débloquer**

```
1. Paramètres > Téléphone > Contacts bloqués
2. Voir la liste de tous vos numéros bloqués

Pour débloquer:
1. Appuyer sur "Éditer"
2. Appuyer sur le (-) rouge
3. Appuyer sur "Débloquer"

ou

1. Aller dans Contacts
2. Trouver le contact bloqué
3. Appuyer sur "Éditer"
4. Appuyer sur "Débloquer ce contact"
```

## 🎓 SECTION CONSEILS DE SÉCURITÉ

### AVANT de Bloquer

**Checklist:**
```
☑️ Vérifiez qui appelle/envoie
   - Est-ce un numéro inconnu?
   - Demande-t-il de l'argent?
   - Crée-t-il de l'urgence?

☑️ Demandez-vous:
   - "Est-ce que ma banque appelle sans demande?"
   - "Un ami m'aurait-il prévenu avant?"
   - "Pourquoi ce SMS soudainement?"

☑️ Ne pas:
   ❌ Cliquer sur les liens
   ❌ Donner vos infos
   ❌ Raccrocher trop vite (vous ne pouvez pas rappeler)

☑️ Faire avant de bloquer:
   ✅ Noter le numéro
   ✅ Signaler à votre banque/entreprise
   ✅ Enregistrer le message SMS
   ✅ Prendre une capture d'écran
```

### APRÈS avoir Bloqué

**Étapes de suivi:**
```
1. SIGNALER
   ➜ Signaler comme spam à votre opérateur
   ➜ Signaler à la police (si arnaque)
   ➜ Signaler à ScamGuard (voir plus bas)

2. DOCUMENTER
   ➜ Sauvegarder le numéro
   ➜ Noter la date et l'heure
   ➜ Décrire ce qui s'est passé

3. PROTÉGER
   ➜ Vérifier votre compte bancaire
   ➜ Changer les mots de passe si nécessaire
   ➜ Activer la double authentification

4. ÉDUQUER
   ➜ Parler à votre famille
   ➜ Partager avec vos amis
   ➜ Sensibiliser aux signes d'alerte
```

## 🚨 SIGNALEMENT

### Comment Signaler un Scam

**À votre OPÉRATEUR téléphonique:**
```
1. Contactez votre fournisseur (Afni, Orange, Proximus, etc)
2. Donnez le numéro qui a appelé
3. Décrivez le scam
4. Demandez un blocage au niveau du réseau

Les opérateurs peuvent bloquer à la source.
```

**À la POLICE:**
```
1. Allez sur: www.police.be/signalement (Belgique)
2. Ou: www.gendarmerie.gouv.fr (France)
3. Ou: www.policia.es (Espagne)
4. Remplissez le formulaire
5. Joignez les preuves (captures d'écran, SMS, etc)
```

**À votre BANQUE (si arnaque financière):**
```
1. Appelez immédiatement votre banque
   (numéro au dos de votre carte)
2. Signalez la transaction suspecte
3. Demandez un blocage de compte si nécessaire
4. Signalez l'escroquerie
```

**À ScamGuard (dans l'app):**
```
1. Aller dans ScamGuard
2. Onglet "Ressources"
3. Appuyer sur "Signaler un scam"
4. Remplir:
   - Numéro/Email
   - Type de scam
   - Description
   - Date/heure
5. Envoyer
```

## ❓ FAQ

### **Q: Qu'est-ce qui se passe quand je bloque un numéro?**
```
R:
- L'appel n'apparaît pas sur votre écran
- Le message n'est pas livré
- Vous n'êtes pas notifié
- Ils ne sauront pas qu'ils sont bloqués
  (sur certains appareils, ils entendront une tonalité occupée)
```

### **Q: Puis-je débloquer un contact?**
```
R: Oui! Vous pouvez le faire n'importe quand.
   Voir les sections "Débloquer" ci-dessus.
```

### **Q: Comment signaler à la police?**
```
R: Visitez:
   🇧🇪 www.police.be/signalement
   🇫🇷 www.gendarmerie.gouv.fr
   🇪🇸 www.policia.es
   🇨🇦 www.rcmp-grc.gc.ca
```

### **Q: Que faire si j'ai déjà perdu de l'argent?**
```
R:
1. Signalez immédiatement à votre banque
2. Demandez un blocage de compte
3. Signalez à la police
4. Conservez toutes les preuves
5. Consultez un avocat si nécessaire
6. Vérifiez votre crédit (www.creditplus.be)
```

### **Q: Ils m'ont appelé depuis le numéro de ma banque!**
```
R: C'est du SPOOFING (faux numéro).
   Les arnaqueurs imitent le numéro de votre banque.

   Solution:
   ✓ Raccrochez
   ✓ Appelez directement votre banque
     (numéro au dos de votre carte)
   ✓ Demandez si l'appel était légitime
```

### **Q: Combien de numéros puis-je bloquer?**
```
R: Illimité! Bloquez autant que vous voulez.
   (Certains appareils très anciens limitent à 250)
```

### **Q: Mon enfant reçoit des messages suspects?**
```
R: Blocage immédiat + Contrôle Parental:

Android:
1. Paramètres > Google Family Link
2. Activer le filtrage des apps
3. Gérer les contacts bloqués

iPhone:
1. Paramètres > Temps d'écran
2. Restrictions de contenu et d'intimité
3. Gérer les contacts
```

## 🆘 EN CAS D'ARNAQUE

### **Vous avez PERDU DE L'ARGENT?**

**ACTIONS IMMÉDIATES:**
```
1. ⏰ DANS LES 24 HEURES:
   ☑️ Contactez votre banque
   ☑️ Demandez un blocage de compte
   ☑️ Signalez la transaction

2. 📋 DANS LES 48 HEURES:
   ☑️ Déposez plainte à la police
   ☑️ Conservez tous les documents
   ☑️ Photographiez les messages/emails

3. 📞 CONTACTEZ:
   ☑️ Votre banque (urgence)
   ☑️ La police (dépôt de plainte)
   ☑️ Centre de récupération de fraude
   ☑️ Votre assurance (si vous l'avez)
```

### **Ressources d'Aide**

**Belgique:**
- Police: 101 (non-urgent) ou 112 (urgence)
- Signalement: www.police.be/signalement
- Fraude bancaire: Contactez votre banque

**France:**
- Gendarmerie: 17 ou www.gendarmerie.gouv.fr
- Signalement: www.phishing-initiative.fr
- Fraude: Contactez votre banque

**Suisse:**
- Police cantonale
- Dépôt de plainte électronique: www.polizei.admin.ch

**Canada:**
- Police: 911 (urgence) ou numéro local
- Fraude: www.antifraudcentre.ca
